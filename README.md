# TIODR

Sitio estático de herramientas digitales gratuitas.

## Publicación
- Rama principal: `main`.
- Dominio personalizado: `www.tiodr.site` (archivo `CNAME`).
- Despliegue automático mediante GitHub Actions en `.github/workflows/pages.yml`.
- Archivos HTML, CSS, JavaScript, sitemap y robots en la raíz para conservar las URL actuales.

## SEO e identidad
- Sitemap: https://www.tiodr.site/sitemap.xml
- Robots: https://www.tiodr.site/robots.txt
- Logo de organización y favicon SVG: `img/favicon.svg`
- Logo horizontal: `img/logo-header.svg`
- Imagen social: `img/og-tiodr.svg`

Después de publicar, revisar la URL de inicio y el sitemap en Google Search Console. La aparición del favicon/logo en Google depende del rastreo y de los sistemas de Google; no se puede garantizar ni forzar.
