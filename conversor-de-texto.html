Modos de Conversión Disponibles

MAYÚSCULAS

Convierte todo el texto a letras mayúsculas. Útil para títulos, encabezados impactantes, código de programación y textos que requieren énfasis máximo.

minúsculas

Convierte todo el texto a letras minúsculas. Ideal para normalizar datos, generar handles para redes sociales o limpiar texto con capitalización mixta.

Capitalizar

Pone en mayúscula la primera letra de cada palabra. Perfecto para nombres de personas, títulos de artículos o nombres de productos.

Formato Título (Title Case)

Similar al capitalizado pero respeta las convenciones de títulos: las palabras cortas como artículos, preposiciones y conjunciones permanecen en minúscula. Recomendado para títulos de artículos y headings SEO.

Formato Oración (Sentence Case)

Pone en mayúscula solo la primera letra de cada oración, igual que en un texto normal. Ideal para limpiar texto en mayúsculas o reestructurar párrafos.

Formato Slug para URLs

Convierte el texto al formato ideal para URLs amigables: todo en minúsculas, sin acentos, sin caracteres especiales, espacios reemplazados por guiones. Ejemplo: "Cómo Crear un Blog en 2024" → "como-crear-un-blog-en-2024". Esencial para SEO on-page.

💡
Para SEO: Usa el modo slug-url para generar URLs perfectas para tus artículos de blog. Una URL limpia sin acentos mejora el CTR y la indexación. Combínalo con el Contador de Caracteres para mantener la URL bajo 75 caracteres.

¿Para Qué Usar el Conversor de Texto?

  • Redacción y edición: Corrige texto pegado de documentos con formatos incorrectos
  • Programación: Normaliza strings, genera constantes en MAYÚSCULAS o variables en minúsculas
  • SEO: Genera slugs perfectos para URLs de artículos y categorías
  • Redes sociales: Da énfasis a tus publicaciones con texto en mayúsculas o AlTeRnAdO
  • Diseño gráfico: Previsualiza cómo quedará el texto en distintos formatos

También puedes usar el Generador de Contraseñas para crear claves seguras o el Generador de QR para convertir tus URLs en códigos QR.

Qué debes revisar después de convertir

Las conversiones son automáticas y no entienden el significado del texto. Al pasar a minúsculas, «Santo Domingo» o una sigla como «ITBIS» también se vuelven minúsculas, y los modos Oración y Título las dejan con la primera letra en mayúscula. Revisa nombres propios y siglas antes de usar el resultado.

Detalles de cada modo

  • Oración: pone en mayúscula la primera letra del texto y la que sigue a un punto, y respeta los signos de apertura ¿ y ¡.
  • Título: capitaliza las palabras principales y deja en minúscula artículos y preposiciones comunes (de, la, en, con…), salvo al inicio o tras un punto.
  • Slug: pasa a minúsculas, quita tildes (la ñ se convierte en n), elimina símbolos y une las palabras con guiones, ideal para direcciones web claras.

Privacidad

La conversión se hace en tu navegador. El texto que pegas no se envía a ningún servidor.
